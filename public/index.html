Integration

Three steps to secure login

You don't need a Ph.D. in cryptography to keep your users safe. We've distilled the integration down to three simple steps.

1

Register App

Create a project in your dashboard to get your unique Client ID and secret.

2

Configure URLs

Tell us where to safely redirect your users after they successfully log in.

3

Add the Link

Add a standard OpenID Connect login link to your app. That's it.

The API

A standard token exchange. No surprises.

Trade a one-time authorization code for signed tokens with a single request. That's the entire contract.

  • RS256-signed access & refresh tokens
  • OIDC discovery & JWKS built in
  • Single-use, time-boxed authorization codes
POST /token 
curl -X POST https://your-domain/token \
  -H "Content-Type: application/json" \
  -d '{
    "code": "auth_9f2c...",
    "clientId": "c14a...",
    "clientSecret": "sk_live_...",
    "redirectUri": "https://usewave.dev/callback"
  }'

# 200 OK
{
  "success": true,
  "data": {
    "accessToken": "eyJhbGciOi...",
    "refreshToken": "eyJhbGciOi...",
    "tokenType": "Bearer"
  }
}
